# Отчет ПР1

Вариант - 5

Окружение - Windows 10, Node.js v26.13.0, npm 11.20.0, git 2.45.1.windows.1, Helium.

Запуск происходит из корня репозитория командами: 
`node js/progress.js`
`node js/hello.js`
`node js/types.js`
`node js/plan.js`
`node js/debug.js`

Для запуска в браузере, редактировать pr1/index.html заменить путь в script на нужный файл, открыть html файл в браузере

| Выражение | Ожидание до запуска | Фактическое значение | Тип результата | Объяснение |
|---|---|---|---|---|
| `"8" + 2` | string | `82` | string | Предположительно, гарантированно успешное преобразование int → string имеет больший приоритет, чем потенциально провальное string → int. |
| `"8" - 2` | number | `6` | number | Вычитание из string сложно определить интуитивно, поэтому логично преобразование числовой строки в число для выполнения математической операции. |
| `Number("8") + 2` | number | `10` | number | Number(x) преобразовывает ввод в число, число + число = число. |
| `"12" > "3"` | boolean | `false` | boolean | Независимо от ввода, функция сравнения может вернуть только boolean. |
| `12 === "12"` | boolean | `false` | boolean | Независимо от ввода, функция сравнения может вернуть только boolean. |
| `Number("")` | number | `0` | number | Number() преобразовывает ввод в число независимо от ввода. При этом при выполнении без ошибки программы ожидалось два исхода: либо вернется число 0, что будет результатом, поддерживающим стабильность возврата числа функцией Number, либо NaN. |
| `Number("text")` | number | `NaN` | number | Number всегда возвращает объект с типом данных number независимо от ввода. Значение неважно. |
| `Boolean("false")` | boolean | `true` | boolean | Boolean всегда возвращает объект с типом данных boolean. |
| `typeof null` | type | `object` | string | Typeof, независимо от ввода, вернет тип ввода. Предположительно, вернулся бы тип данных, специально созданный для хранения типов, но оказалось, что данные возвращаются в виде текстовой строки. |
| `typeof NaN` | string | `number` | string | Как выяснилось в прошлом выводе, typeof возвращает string. |
